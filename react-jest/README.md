# React + TypeScript kata kickstart (Jest + Testing Library)

```bash
npm install
npm run dev            # Vite dev server
npm test               # all tests (unit + ui)
npm run test:unit      # tests/unit/**/*.test.ts   (node env)
npm run test:ui        # tests/ui/**/*.test.tsx    (jsdom + Testing Library)
npm run test:watch
npm run typecheck
npm run format
```

TypeScript is pinned to 6.x because ts-jest does not support TypeScript 7 yet.
